COLLECTE HÔTE · DOCKER / SMART

Installer le collecteur UGOS

La console n'a volontairement pas accès au socket Docker. Pour obtenir les compteurs Docker et SMART, installe un petit script en lecture seule dans le planificateur de tâches UGOS. Il crée les fichiers dans /volume1/docker/nas-dashboard/metrics.

Voir le script collect-nas.sh ↗

Étapes : télécharger ce script sur ton NAS, le consulter, lancer une première fois en SSH, puis créer une tâche UGOS exécutée chaque minute. Pour SMART, smartctl doit être installé et la tâche doit disposer des permissions nécessaires. Ne monte pas docker.sock dans le dashboard.

sudo mkdir -p /volume1/docker/nas-dashboard/metrics
sudo sh /volume1/docker/pablohflix-native-preview/collect-nas.sh

La deuxième commande suppose que tu as placé le script à cet emplacement. Dans UGOS, planifie exactement cette commande avec les droits nécessaires, puis vérifie le statut ci-dessus.

STOCKAGE

Volumes 1 & 2

L'espace du Volume 1 est relevé automatiquement via /app/data. Pour le Volume 2, crée un dossier vide dédié et ajoute ce montage dans le projet Docker :

# À effectuer une seule fois sur le NAS
sudo mkdir -p /volume2/pablohflix-probe
# Montage en lecture seule dans la section volumes du Compose
- /volume2/pablohflix-probe:/app/volume2-probe:ro

Ce répertoire vide suffit pour lire les capacités du système de fichiers. Le montage n'expose ni les films ni les enregistrements.

RÉSEAU & VPN

Choisir les sources Gluetun

Crée d'abord une intégration Gluetun dans l'onglet Intégrations API. Puis sélectionne ici les deux connexions (media et recordstudio). La console interrogera leurs endpoints de statut et d'IP, sans modifier le Compose pour chaque API.

L'API de contrôle de Gluetun doit être accessible au conteneur PabloHFlix sur son réseau Docker, et configurée en lecture seule pour ces requêtes lorsque c'est possible.

CONFIGURATION

Export & restauration

L'export contient les cartes, les lignes et les références d'intégration, sans clé API. Conserve séparément une sauvegarde du dossier Docker data/ et de ta clé de session pour une restauration complète.

Réinitialiser les cartes remet les cartes Jellyfin, Media-arr et Recordstudio de la V1, sans supprimer les intégrations ni leurs clés.
